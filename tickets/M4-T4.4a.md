NOTES (Architect rulings):
  - build_info.dart is one declaration:
      const String appVersion =
          String.fromEnvironment('APP_VERSION', defaultValue: 'dev');
    SAME TRAP AS T4.0: fromEnvironment is only guaranteed inside a
    const context. Keep the const. Doc-comment one
    --dart-define=APP_VERSION=1.0.0-beta example. T4.6 wires the real
    value into store builds; nothing else changes today.
  - Lobby footer: a small, muted 'v' + appVersion, bottom-center,
    every lobby state. Cosmetic only.
  - Retry: when NOT connected, an outlined RETRY button directly
    under the DISCONNECTED status, calling
    appState.triggerReconnect(). Hidden while connected. Test: set a
    counting reconnect callback, tap, expect exactly one call; and
    absent when connected.
  - Error copy in app_state, verbatim:
      0x01 → "That room's full — grab a fresh code."
      0x02 → "No room with that code — it may have expired."
      unknown → "Something went sideways (0xNN). Try again."
    Keep the hex in the unknown line — it is the one place a
    screenshot has to carry the diagnosis.
  - Tidy-up (a), from the #16 review: in main.dart,
      resolveRejoinStore().then(appState.attachRejoinStore)
    gains .catchError((_) {}) — a platform that cannot answer for a
    documents directory means the feature is off, never a crash.
  - Tidy-up (b): when PEER_LEFT lands and the engine goes abandoned,
    unawaited-clear the rejoin save. The server just stated the room
    is dead — that is a fact off the wire, not a client conclusion,
    so acting on it honors ADR-003 rather than bending it. One
    app_state test: PEER_LEFT clears; and the existing
    manual-join-error test still proves 0x02-without-pending does not.
  - TRAP: existing lobby tests pump a disconnected default state —
    the new RETRY button will appear inside their trees. Fix finders
    and counts; do not restructure the tests to dodge it.
  - Do NOT touch signaling_service: its status strings never reach
    the UI (only the ==Connected bool does), so there is nothing to
    make friendly there. Leave the layer alone.
