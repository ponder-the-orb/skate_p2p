TICKET M2-T2.1 — GameEngine: deterministic rules reducer
GOAL: The full S.K.A.T.E. state machine as pure Dart. Every row of
ARCHITECTURE.md §5's rules table becomes a test.

FILES:
  - new lib/game/game_engine.dart
  - new test/game_engine_test.dart

SPEC: ARCHITECTURE.md §5 (rules table, phases), ADR-006 (pure Dart)

NOTES (Architect rulings):

Pure Dart reducer: (state, event) -> new state. Immutable — apply()
returns a new GameState, never mutates. No imports except dart:core.
No Flutter, no net/, no ui/, no debugPrint, no globals.

Naming: file is game_engine.dart; the immutable state class is
GameState with `GameState apply(GameEvent e)`. Callers do
`state = state.apply(e)`.

LETTERS ARE KEYED TO PLAYER ID, NOT TO ROLE. Roles swap during play;
letters must not travel with the role. Use
`Map<int,int> letters` (playerId -> 0..5). This is the single most
important detail in this ticket.

Events (sealed classes):
  - GameStarted(firstSetterId, firstDefenderId) — engine needs BOTH
    ids; caller derives them from role in JOINED/PEER_JOINED
  - TrickSet(playerId, name)
  - AttemptResult(playerId, landed)
  - RematchVote(playerId)
  - PeerLeft(peerId)

State (all public, all immutable):
  enum GamePhase { lobby, setting, defending, gameOver, abandoned }
  phase, setterId, defenderId, letters (Map<int,int>),
  currentTrickName (String?), rematchVotes (Set<int>),
  firstSetterId (who set first THIS game — needed for rematch),
  winnerId (String? / int?, set at gameOver)

Rules (one test per row, test names mirror the row):
  setting   + setter bails    -> roles swap, stay setting, no letter,
                                 trick cleared
  setting   + setter lands    -> defending, trick locked
  defending + defender lands  -> setting, SAME setter, trick cleared
  defending + defender bails  -> that player's letters +1;
                                 if now 5 -> gameOver (winner = setter),
                                 else setting, same setter
  gameOver  + both RematchVote-> letters reset 0/0, votes cleared,
                                 roles flip (last game's first defender
                                 sets first), phase setting
  any       + PeerLeft        -> abandoned

Invalid events (wrong player, wrong phase, unknown id) return the state
UNCHANGED. No throwing, no logging — the engine has no logger. Optional:
a `lastRejectedReason` String? field for debugging.

DEFINITION OF DONE:
  - one test per rules row (6) + letters accumulate 1..5 to gameOver
    + rematch needs BOTH votes (one vote = still gameOver)
    + PeerLeft tested from setting, defending, and gameOver
    + invalid events leave state untouched
    + KEY TEST: letters stay with the player across a role swap
      (p1 has 2 letters, setter bails, roles swap, p1 STILL has 2)
  - flutter test passes, flutter analyze clean
  - zero imports beyond dart:core in game_engine.dart
  - CHANGELOG entry under [Unreleased]
  - five-line report per WORKFLOW.md §4, with test count

OUT OF SCOPE: all UI (T2.2). AppState/network wiring and protocol v1
game opcodes (T2.3, still this milestone). Last-try variant.

IF IT BALLOONS: land the 6 core rows + tests, report DONE-PARTIAL,
rematch splits to T2.1b.
