NOTES (Architect rulings):
  - Server, strict v1 now: every frame validated per §3 (version byte
    0x01 required). Control range 0x00–0x0F terminates at the server;
    only JOIN is valid inbound. Game range 0x10–0x2F forwards verbatim
    to the one other socket in the sender's room, never echoed. 0x30+
    drop + log. DELETE the transitional first-byte legacy forwarding.
    Send PEER_JOINED to the joiner too (updated §5).
  - Codec adds: TRICK_SET 0x10 (nameLen u8 + UTF-8 name; nameLen 0
    legal = unnamed), ATTEMPT_RESULT 0x11 (0x00 bail / 0x01 land, any
    other value drop + log), REMATCH 0x13 (payload 0). Byte fixtures in
    tests: TRICK_SET unnamed from player 7 = 01 10 00 07 01 00;
    ATTEMPT_RESULT landed from 7 = 01 11 00 07 01 01 (§7); REMATCH
    from 7 = 01 13 00 07 00.
  - Dispatcher: all inbound frames are v1 now. Validate per §3, route
    control opcodes to the existing AppState handlers, game opcodes to
    AppState.applyRemoteEvent(decoded). Delete the legacy 0x02/0x03
    path entirely.
  - AppState holds `GameState game = GameState.initial()`. Seeding:
    each client fires GameStarted when it knows BOTH ids — creator
    (role 1) on PEER_JOINED: GameStarted(myId, peerId); joiner (role 2)
    on PEER_JOINED: GameStarted(peerId, myId).
  - Local intents (setTrick / reportResult / voteRematch): apply to the
    engine FIRST; if lastRejectedReason is set, do nothing further.
    Otherwise encode + send the matching packet. Remote packets: decode
    → apply. Same events, same order, both engines agree — that is the
    whole sync model (ADR-003).
  - PEER_LEFT (control) now also feeds the engine a PeerLeft event
    before the existing reconnect-to-lobby flow runs.
  - DELETE from AppState: isMyTurn, localLetters, peerLetters, and
    their setters. UI derives everything from `game` + playerId.
  - match_screen, functional only: derived-phase text ("You set" /
    "They set" / "Match their trick" / "Waiting…"), trick name field +
    Set button (empty = unnamed) when you're the setter, LANDED / BAILED
    buttons when it's your attempt, letters per player from
    game.letters, plain gameOver text (win/lose) + REMATCH button,
    Leave button unchanged. No styling effort — T2.3 owns looks.
  - No new dependencies. Layering per ARCHITECTURE §3: game/ imports
    nothing; state/ may import game/ and be called by net/ glue wired
    in main.dart.
