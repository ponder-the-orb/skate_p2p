TICKET M3-T3.3 — Reconnect grace (STATE_SYNC)
GOAL: A dropped player can rejoin within the grace window and resume
the exact game — letters, roles, trick, votes. Survivor sees a
countdown; expiry behaves exactly like today's PEER_LEFT.
BRANCH: m3/reconnect-grace — push, open PR, never touch main.
FILES:
  - skate_signaling_server/server.js · test/rooms_smoke.js
  - lib/core/network/packet_codec.dart · packet_dispatcher.dart
  - lib/core/state/app_state.dart
  - lib/ui/screens/match_screen.dart
  - test/packet_codec_test.dart · app_state_test.dart · match_screen_test.dart
SPEC: PROTOCOL.md §5 (0x05/0x06 + grace rules), §6 (0x12 STATE_SYNC),
§3 validation; ARCHITECTURE.md §4 + ADR-003.
NOTES (Architect rulings):
  - ZERO lines change in lib/game/. The rejoiner installs the snapshot
    by constructing GameState(...) via its existing public constructor
    inside AppState. If you think you need an engine change, STOP and
    report BLOCKED.
  - Server: grace per room — vacant slot remembers playerId+role;
    GRACE_MS module const (120000), overridable via env GRACE_MS so
    tests run at 200ms. Timers cleared on rejoin, expiry, and
    survivor-leave (survivor's socket closing during grace = delete
    room immediately, cancel timer, no late-fire crash). JOIN with the
    room code during grace re-seats the ORIGINAL playerId+role: send
    JOINED as normal, then 0x06 to BOTH; PEER_JOINED is never re-sent.
    Expiry: PEER_LEFT to survivor, delete room. Game frames arriving
    while the peer slot is vacant: drop + log (no ERROR).
  - Anyone holding the code can claim the vacant seat — accepted, per
    the §5 trust model. Do not invent auth.
  - Codec: 0x05 (peerId, graceSeconds) · 0x06 (peerId) · 0x12 per the
    spec table. Encode player pair lower-id-first; decode is
    order-agnostic. winnerId 0 = none. flags bit0 trickDeclared,
    bit1 playerA voted, bit2 playerB voted; trickDeclared=1 with
    nameLen=0 decodes to name '' (unnamed), flag 0 → name null.
    Validate: phase ∈ {1,2,3}, letters ≤ 5, nameLen ≤ 234, UTF-8 in
    try/catch — any failure drops + logs, never throws.
  - AppState, survivor: on 0x05 set peerDisconnected + graceSeconds,
    engine untouched; on 0x06 clear it and — iff game.phase is
    setting/defending/gameOver — encode + send 0x12 once. PEER_LEFT
    path is UNCHANGED.
  - AppState, rejoiner (fresh launch): JOIN(code) → JOINED restores
    the old id → on 0x06 set peerId + awaitingSync=true → accept 0x12
    ONLY while awaitingSync (else drop + log) → install snapshot,
    awaitingSync=false, inMatch.
  - UI: survivor gets a banner "Opponent reconnecting… Ns" counting
    down locally from graceSeconds — cosmetic only, PEER_LEFT is the
    sole authority (at 0 show "any moment…"); intent buttons disabled
    while peerDisconnected. Rejoiner shows "Restoring game…" while
    awaitingSync. Attempt timer needs no special handling (advisory).
ACCEPTANCE:
  - rooms_smoke.js (GRACE_MS=200): drop → 0x05 with graceSeconds;
    rejoin → SAME playerId+role in JOINED, 0x06 to both, no
    PEER_JOINED; expiry → PEER_LEFT + room deleted; survivor-leave in
    grace → immediate delete, no timer crash; in-grace game frame
    dropped.
  - codec: 0x12 byte-fixture round-trip incl. winnerId 0, flag
    combos, unnamed-vs-undeclared; out-of-range phase/letters
    dropped; 0x05 fixture.
  - app_state (cross-fed): survivor emits 0x12 on 0x06; a fresh
    AppState fed JOINED(old id)+0x06+0x12 deep-equals the survivor's
    game; 0x12 outside awaitingSync is ignored.
  - widget: banner + disabled intents while peerDisconnected;
    restoring state while awaitingSync.
  - analyze ✅ test ✅ format ✅ · CHANGELOG · five-line report + PR.
  - Manual (Producer): kill app mid-game → countdown on survivor;
    relaunch + rejoin → identical state resumes. Separate run: let
    grace expire → survivor lands in lobby.
OUT OF SCOPE: engine diffs (must be 0), auth/seat-hijack prevention,
pausing the attempt timer, ranked durations (server const only).
IF IT BALLOONS: land server + codec + dispatcher + their tests,
report DONE-PARTIAL; AppState/UI split to T3.3b.
